📖 Документация Cherry Client

Полное описание всех функций, настроек и консольных команд

🎯 Аимбот - Основное

Главные настройки наведения и визуализации цели.

Настройка Описание Консольная команда Диапазон
Включить Активирует основной модуль Аимбота cherry_aim_enable 0 / 1
Рисовать FOV Отображает круг радиуса поиска цели на экране cherry_aim_drawfov 0 / 1
Бокс цели Рисует квадрат вокруг игрока, в которого наведен аимбот cherry_aim_box 0 / 1
Свечение цели Добавляет эффект свечения к цели cherry_aim_glow 0 / 1
Идеальный Silent Пули/крюк летят точно в цель, но визуально камера не поворачивается cherry_aim_silent 0 / 1
Мин. задержка Минимальная задержка перед выстрелом (в мс) cherry_aim_mindelay 0 - 1000
Макс. задержка Максимальная задержка перед выстрелом (в мс) cherry_aim_maxdelay 0 - 1000

🪝 Крюк

Настройки авто-захвата крюком.

Настройка Описание Консольная команда Диапазон
Включить Включает аим на крюк cherry_hook_enable 0 / 1
FOV (Угол обзора) Радиус поиска цели для крюка (в градусах) cherry_hook_fov 1 - 360
Приоритет Выбирает цель, которая ближе всего к прицелу cherry_hook_priority 0 / 1
Silent (Бесшумно) Крюк цепляется без визуального поворота камеры cherry_hook_silent 0 / 1
Игнорировать друзей Не будет наводиться на игроков из списка друзей cherry_hook_ignore_friends 0 / 1
Точность Процент точности наведения крюка cherry_hook_accuracy 1 - 100

🔨 Молот

Настройки авто-удара молотом.

Настройка Описание Консольная команда Диапазон
Включить Включает аим на молот cherry_hammer_enable 0 / 1
FOV (Угол обзора) Радиус поиска цели для молота cherry_hammer_fov 1 - 360
Приоритет Выбирает цель ближе к прицелу cherry_hammer_priority 0 / 1
Silent Удар происходит без визуального поворота cherry_hammer_silent 0 / 1
Игнорировать друзей Не бьет игроков из списка друзей cherry_hammer_ignore_friends 0 / 1

🔫 Пистолет / Дробовик

Включение авто-стрельбы для огнестрельного оружия.

Настройка Описание Консольная команда Диапазон
Пистолет (Вкл) Автоматическая стрельба из пистолета при наведении cherry_pistol_enable 0 / 1
Дробовик (Вкл) Автоматическая стрельба из дробовика при наведении cherry_shotgun_enable 0 / 1
